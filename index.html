01 · INTRODUCTION

What is K-Means Clustering?

K-Means is an unsupervised machine learning algorithm used to divide data into K groups, called clusters. It places similar data points in the same cluster based on their features. Unlike supervised learning, it does not require pre-labelled target classes.

🎯

Find groups

Discover natural groupings in data when the correct labels are not already known.

📍

Use centroids

A centroid represents the centre of a cluster and is updated as assignments change.

🔁

Repeat and improve

Assign points and recalculate centres until the clusters stabilise or a stopping rule is met.

04 · HOW IT WORKS

The K-Means Algorithm

1
Choose K
Decide how many clusters to create.
2
Initialise centroids
Choose K starting centre points, often using a method such as K-Means++.
3
Assign data points
Assign each point to its nearest centroid, commonly using Euclidean distance.
4
Update centroids
Calculate the mean position of the points assigned to each cluster.
5
Repeat
Repeat assignment and updating until assignments stop changing or a stopping limit is reached.
05 · MATHEMATICS

Important Formulas

Euclidean distance

d(x, μ) = √Σ(xᵢ − μᵢ)²

Measures the straight-line distance between a data point x and a centroid μ.

Centroid update

μⱼ = (1 / nⱼ) Σ xᵢ

The new centroid is the mean of the points assigned to cluster j.

Objective function

WCSS = Σⱼ Σᵢ∈Cⱼ ||xᵢ − μⱼ||²

K-Means seeks to minimise the total squared distance within clusters.

Notation: x is a data point, μ is a centroid, nⱼ is the number of points in cluster j, and Cⱼ is the set of points assigned to cluster j.

07 · EVALUATION

Advantages and Limitations

✅ Advantages

  • Easy to understand and implement.
  • Works well on many numeric datasets.
  • Can efficiently group large datasets with suitable implementations.

⚠️ Limitations

  • K must be chosen in advance.
  • Initial centroids can affect the result.
  • Outliers and feature scales can influence clusters.
  • May perform poorly on irregularly shaped clusters.

💡 Practical tip

Scale features when appropriate and compare candidate values of K using methods such as the elbow method and silhouette score.

10 · CONCLUSION

Conclusion

K-Means Clustering is a widely used unsupervised machine learning algorithm that organises data into groups based on similarity. It works by assigning data points to the nearest centroid and repeatedly updating the centroids until the clusters stabilise. This project demonstrates how the choice of K changes the grouping process and explains the algorithm's mathematical foundation, practical uses and limitations. K-Means is a useful starting point for discovering patterns in unlabelled data, although results depend on the data, feature scaling and centroid initialisation.
